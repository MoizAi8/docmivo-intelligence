# Final stack and compatibility policy
- Next.js App Router, React compatible with the chosen stable Next.js release, strict TypeScript; Node 24 LTS if Vercel supports it, otherwise supported LTS. npm lockfile. No canary dependencies unless framework requires them; verify current security patches and peer dependencies at bootstrap.
- Tailwind CSS, accessible Radix primitives/shadcn selectively, Motion for UI, GSAP ScrollTrigger only on landing if useful, Lucide, local licensed fonts (Manrope or DM Sans; editorial heading optionally Fraunces). No WebGL requirement.
- Server-only TypeScript modules and route handlers; Zod; Auth.js stable compatible release or established maintained auth library with DB-backed sessions, secure cookies and CSRF protection. Use vetted password hashing if passwords chosen. Invite-only defaults. No handrolled JWT/auth crypto.
- Neon PostgreSQL supported stable version (prefer 18 if available and all extensions/driver work; otherwise 17). Drizzle ORM + explicit SQL migrations for FTS, trigram, optional pgvector and RLS. Use transaction-capable PostgreSQL driver appropriate for Node runtime; pooled runtime URL, direct migration URL. Separate runtime/migration privileges. No browser database credentials. No SQLite as production or as proof of PostgreSQL concurrency.
- Indexed PostgreSQL FTS (GIN), pg_trgm, B-tree tenant/date/status indexes; optional pgvector only if genuine approved embeddings, versioned dimensions and measured retrieval. For small data exact tenant-scoped vector ranking is acceptable; HNSW only after measurement.
- PDF parser PDF.js/pdfjs-dist with pinned compatible release; Mammoth raw text for DOCX, UTF-8 TXT/MD. No HTML rendering from parsers. Use parser isolation/worker with enforced limits. Browser PDF viewer served via authorized private download or stream, no remote CDN worker. Validate real file signatures; DOCX zip limits. Scans/OCR are optional.
- Storage: dedicated PostgreSQL private bytea table for bounded small files (default 2 MiB per file, 20 MiB/workspace), avoiding external public object store, only if platform request/response/runtime limits tested. Upgrade to private object storage with authenticated download and short-lived server-controlled access if justified; verify free quota. No public blobs. Separate storage adapter.
- AI: official Google GenAI SDK, environment-configured stable Flash/Flash-Lite model; verify supported model ID and current terms. Free external AI only synthetic or explicitly eligible non-sensitive data; private files never sent to external inference or embeddings. Optional locally hosted embedding/inference if verified and authorized, not required to deploy free tier. No user secrets copied between apps.
- Vitest, Playwright, axe-core, PostgreSQL integration tests, dependency audit, GitHub Actions. Vercel Node runtime + dedicated Neon Free; verify plans, file body limits, function deadlines, regions, storage and quota before implementation. No paid services. If durable background worker cannot be hosted, use bounded synchronous/resumable processing with DB state; no fake worker.
