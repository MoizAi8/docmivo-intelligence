# Architecture
Browser -> Next.js Node server -> auth and tenant authorization -> domain services -> PostgreSQL. Document bytes and extracted chunks remain private. UI never queries database directly. Separate modules: auth, workspace, upload, storage, parser, ingestion, search, AI policy, retrieval, citations, notes, quotas, audit. Server validates all input with schemas.
Upload: authenticate -> enforce quota and file bounds -> validate signature -> store private file + job atomically -> parse within isolated bounded execution -> normalize page/section text -> chunk with stable offsets -> build indexes -> commit READY state. Parser errors become FAILED with safe message. Use idempotency key and content hash scoped per tenant. No cross-tenant dedupe leakage. Do not rely on asynchronous execution after HTTP response. For Vercel, prove bounded processing fits deadlines or use resumable authenticated job steps; return explicit status and retries. If parser isolation cannot be verified, restrict types/size and do not claim safe arbitrary uploads.
Search: normalize query -> authorize workspace -> title/tag/full-text/trigram results -> rank and dedupe -> safe snippet -> page/section link. Separate retrieval from response generation. No provider call on keyword search. AI: classify eligibility -> require explicit request consent -> retrieve only eligible tenant chunks -> quota transaction -> call configured provider with minimal context -> validate answer/citations -> persist result. No private text sent to provider. Query may itself be sensitive; require non-sensitive question confirmation and disallow external transmission for private workspace mode. AI answers derived from eligible sources only; insufficient evidence produces explicit abstention. No tools/actions from retrieved instructions.
Data deletion: revoke access/search visibility in transaction, delete related chunks/embeddings/citations or tombstone and purge, retain only minimal content-free audit events; verify cleanup and document provider/backups retention limitations. Cache only tenant-keyed non-sensitive results or no cache; no shared CDN for content. Use no-store for protected responses. Server-side limits for upload, parse, searches and AI. Logs only metadata and safe codes.
