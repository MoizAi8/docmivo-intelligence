# Search and intelligence specification
## Fast search P0
Search title, folder/tag, extracted document chunks and saved note/answer text (authorized only). Use PostgreSQL websearch_to_tsquery or plainto_tsquery with bound parameters; simple language config supports exact multilingual terms, optionally use language-specific stemming with verified detection. GIN on generated tsvector or migration-managed tsvector, pg_trgm for typos/title prefix, B-tree tenant and status. Search candidates scoped to workspace and READY/nondeleted status before ranking. Weight exact title matches, exact phrase, content rank, fuzzy title and recency modestly. Cap query 160 chars, page size 20, max 50, cursor stable tie-break. Debounce 180ms client, cancel stale requests; return results immediately with matched terms, source title, page/section, snippet and stable ID. Escape text in UI; highlight via text segments, no unsafe HTML. Recent queries local/private optional, clear history. Filters: type, folder, tags, date, favorites; saved searches persisted. Ctrl/Cmd+K, arrows, Enter/Escape. No AI dependency. Measure warm p50/p95 target <=250ms API at 5k–10k synthetic chunks (report actual and hosted cold separately). Benchmark cross-user negative cases and EXPLAIN indexes. Never guarantee instant results.
## Optional hybrid
If privacy-compatible embedding provider exists, generate versioned embeddings only for eligible content. Use dimension verified at runtime, tenant filtering, lexical + cosine results fused by reciprocal rank; assess recall@k on known queries. If none, ship lexical retrieval and accurately label it, no fake semantic search. Private local embedding computation only if actually isolated and supported; browser embedding must not transmit private data.
## Real AI
Chunk ~350–650 tokens, overlap 50–80, preserve PDF page or document heading + char offsets. Retrieve 6–10 relevant chunks within bounded context; cite chunk IDs and page/section. Supply untrusted content as data, never instructions. Schema {answer, citations:[{chunkId, quote}], insufficientEvidence}. Validate IDs against retrieved set and quote against source (normalized whitespace only). Reject invalid citations, retry at most once within quota or abstain. No claim of truth beyond sources. Comparison and summary also require citations. Never send private docs, private notes, or mixed private/eligible context to free provider. Explicit eligibility, synthetic-only default for external AI; require non-sensitive confirmation, clear disclosure. No provider calls from search or ingestion of private files. Tests must inspect outbound payload redaction and refusal behavior.
