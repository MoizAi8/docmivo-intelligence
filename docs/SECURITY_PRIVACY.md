# Privacy threat model and release policy
Sensitive documents are the product's principal risk. Default all uploads PRIVATE. Keyword search works without third-party AI. Free Gemini terms may allow submitted content to be used for product improvement; verify official terms (https://ai.google.dev/gemini-api/terms) at deployment. Do not send confidential/personal/regulated data to free Gemini, including query, embeddings, excerpts, notes or metadata. External AI defaults to synthetic sample workspace/documents only; explicitly eligible non-sensitive uploads may be enabled for authorized users with informed per-request confirmation and server-enforced classification. UI warns not to use personal/confidential data; consent does not override private classification. Do not claim automated detection catches all sensitive info. Never silently downgrade privacy policy. Paid provider or private inference requires explicit authorization and terms review. Public invite-only, no anonymous upload or unlimited inference.
Threats: IDOR, cross-tenant search/citations, unsafe file parser, zip bombs, malicious PDF actions, HTML/Markdown XSS, prompt injection, SQL injection, quota race, session fixation, CSRF, leaked logs or env, SSRF, public blobs, cache poisoning, deletion residue. Controls: vetted auth, secure HttpOnly SameSite cookies, session expiration, origin/CSRF, least privilege, parameterized queries, tenant-scoped joins and composite FKs, separate roles, RLS where verified, CSP, nosniff, private no-store, no remote resource fetching, safe text renderer, upload allowlist/signature/size/page/decompression/time limits, parser isolated and bounded, no macros or embedded JS, deny executable formats, error messages safe. Do not describe file validation as malware scanning. Use rate limiting and concurrency quotas across instances; auth attempts and upload/search/AI separately. No API keys printed even in exceptions. Never log file names if sensitive, raw documents, search text, or prompt payload. No external analytics on private pages. Document retention/deletion, backup limitations, and user export; no promises of immediate removal from backups/provider. Check all public repository history for secrets and private assets. Rotate exposed keys; redact logs. Test with two synthetic users, isolated PostgreSQL, and malicious fixtures. Do not release public access if high severity unresolved.

## Provider eligibility gate
Gemini official terms (effective March 23, 2026, checked November 26, 2026) restrict API clients to eligible adult users and available regions, professional/business purposes, and require paid services for clients made available to users in the EEA, Switzerland or UK. Verify current terms and implement enforceable eligibility restrictions before enabling external AI; if not feasible, keep external AI restricted to authorized eligible private testers and leave keyword search available. Never enable billing without approval. https://ai.google.dev/gemini-api/terms
