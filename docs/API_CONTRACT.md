# HTTP contract (adjust route layout, preserve behavior)
All JSON responses use {data,requestId} or {error:{code,message},requestId}; no secrets/stack traces. 400 validation, 401 unauthenticated, 403 unauthorized or 404 for hidden resources, 409 conflict, 413 too large, 415 unsupported, 429 quota, 503 provider unavailable. Auth cookie, CSRF/origin checks for mutations as appropriate. Never trust client workspace identifiers without membership verification. No-store for private responses.
GET /api/documents?cursor&type&folder&tag&status; POST /api/documents multipart upload with classification default PRIVATE, idempotency key; GET/PATCH/DELETE /api/documents/:id; GET /api/documents/:id/content (authorized stream, correct MIME, nosniff, attachment for risky content); GET /api/documents/:id/chunks; POST /api/documents/:id/retry; GET /api/jobs/:id. Upload returns doc/job IDs and status, not file URL.
GET /api/search?q&folder&type&tag&cursor returns [{documentId,chunkId,title,snippetSegments,page,section,score,kind}], nextCursor. Search notes only authorized; no cross-tenant cache. POST/GET/DELETE /api/saved-searches. CRUD /api/folders, /api/tags, /api/bookmarks; authorization mandatory.
POST /api/ask {conversationId?,documentIds?,question,allowExternalNonSensitive:boolean,idempotencyKey}; returns validated answer, citations, messageId or explicit blocked/insufficient-evidence state. Never treat consent as permission to transmit PRIVATE files. POST /api/summarize, /api/compare, /api/extract (P1) same policy. GET /api/conversations, GET/PATCH/DELETE /api/conversations/:id; notes CRUD. GET /api/citations/:id resolves authorized source. GET /api/usage, /api/activity, /api/settings; account/workspace deletion; admin health aggregate only. Public /api/health returns minimal status without secrets. Auth library routes per library. Add schemas and tests for all actual routes, keep docs aligned.
