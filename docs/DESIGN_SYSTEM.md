# Docmivo design system — final, replaces violet/teal concepts
Warm editorial productivity: ivory #F8F4ED, copper #C45124, espresso #241D19, sand #E9D5BD, white #FFFFFF; muted #72645A, deep copper #A33E1B for small text and accessible links, border #E2D6C8. Verify actual WCAG contrast, especially white on copper; use deep copper if needed. Dark mode optional: #201A17 surface, #2C2420 panels, #F8F4ED text, #F5A574 accent. Logo: original stylized D-document/search mark in copper square, docmivo. wordmark, tagline Find what matters. Editable SVG included. Do not revert to purple/lavender or neon black design. Fonts: Manrope/DM Sans, optional editorial Fraunces headline, monospace for code/metadata; self-host legally. 4/8 spacing, 12–16px panels, subtle borders, limited shadow. Strong typography and asymmetrical landing composition. Workspace should feel like premium research software, not a generic card dashboard.
## Layouts
Landing: top logo + Product/Security/Sign in, oversized editorial headline, animated document stack -> indexed search -> source highlight -> cited answer, CTA Launch workspace. Product story sections, search demo (illustrative only), library/AI/security features, FAQ and footer. No claims about unmeasured speed/privacy. Workspace: desktop left 230px library nav, top search + Ctrl+K, center document table/cards, optional right details panel. Reader: left outline, middle document/text, right cited assistant; responsive resizable panels, collapse to tabs on mobile. Search overlay: query, filters, keyboard arrows, snippets, source location, open exact result. Results visible without waiting for AI. Detail views: citations are numbered clickable source chips; preview highlighted text, page label. Upload: dropzone, explicit privacy classification, progress/state, clear errors, retry. New workspace empty state with optional synthetic sample import. No fake charts.
## Motion
Landing-only coordinated entrance: 0–250ms wordmark/text, 200–700ms document stack stagger, 600–1300ms search query and source highlight, 900–1500ms answer panel; scroll reveals for feature chapters; no scroll hijacking. Use real HTML/SVG or CSS, Motion/GSAP only when helpful. Respect reduced motion, no continuous GPU work. App motion 120–200ms, no artificial search delay. Mobile 360px min layout, no horizontal overflow. Check 390, 768, 1280, 1440, 1920 widths. Contrast, focus rings, dialog traps, Escape, keyboard, screen-reader labels. Save screenshots and a short recording where possible.
