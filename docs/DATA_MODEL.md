# Logical schema (adapt with explicit migrations)
All IDs UUID; UTC timestamps; foreign keys, non-null constraints, check constraints and indexes. Tenant-owned rows include workspace_id. Composite unique (workspace_id,id) and composite FKs for child references prevent cross-tenant relationship mistakes. Auth library tables separate; do not handroll session schema if library provides it.
- users, sessions/accounts as auth library; workspaces(id, owner_id, name, created_at), memberships(workspace_id,user_id,role) unique pair; roles owner/member if enabled, deny by default.
- folders(id,workspace_id,parent_id,name); tags(id,workspace_id,name normalized unique); document_tags composite FK; favorites unique (workspace,user,doc).
- documents(id,workspace_id,folder_id,title,mime,size,sha256,classification PRIVATE or ELIGIBLE_NON_SENSITIVE, status UPLOADED/PARSING/READY/FAILED/DELETING, error_code, created_at, updated_at, deleted_at), enforce size >0, workspace scoped hash; allow legitimate duplicate names.
- document_files(workspace_id,document_id, bytes BYTEA or private_storage_key, content_type,size); no direct public access.
- ingestion_jobs(id,workspace_id,document_id,state,attempts,lease_until,idempotency_key,created_at,updated_at) unique workspace/idempotency, compare-and-set states; stale recovery.
- document_chunks(id,workspace_id,document_id,ordinal,page nullable,section nullable,start_offset,end_offset,text,search_vector,embedding optional,embedding_model optional), unique doc/ordinal; GIN vector for full text; FK document scope; index workspace,doc,status via join.
- conversations(id,workspace_id,user_id,title,created_at), messages(id,workspace_id,conversation_id,role,content,created_at,status), citations(id,workspace_id,message_id,chunk_id,quote,page); enforce same workspace and user conversation authorization. Notes(id,workspace_id,user_id,title,text,source_message_id), saved_searches(id,workspace_id,user_id,query,filters), document bookmarks.
- usage_buckets(scope_key,period_start,kind,count) unique scope/period/kind; reserve per-user and global counts transactionally in consistent lock order, no quota oversell. usage_events(id,workspace_id,request_id,status,model,latency_ms,token_counts) unique request; no payload logs. audit_events(workspace_id,actor_id,action,target_id,created_at,safe_metadata) no content.
- optional document_versions and extracted_facts with source chunk FKs, only P1.
RLS defense in depth when safe: restricted runtime role cannot bypass RLS; set tenant context transaction-locally on same connection; never global session state in pool. Test policies and application auth. If RLS not implemented, disclose; mandatory application filters always. DB backups/restore and schema migration rehearsal on isolated DB. Deletion cascade/explicit cleanup tested; no irreversible production migration without backup. Document bytes at-rest protection relies on verified hosting configuration; do not claim end-to-end encryption.
