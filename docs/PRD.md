# Product requirements
Docmivo: Find what matters. Audience: individuals, researchers and small teams searching their own saved files. Core objective: retrieve a fact quickly without reading every file. Release is a real functioning, invite-only portfolio application with synthetic examples, not a simulated AI workspace. No enterprise compliance claims.
## P0 release
Public animated landing, product/security pages, accessible navigation, real registration or invite-based access, secure session, onboarding, dashboard, upload PDF/text/Markdown/DOCX (only formats safely supported), library/grid/list, folders, tags, favorites, recent documents, rename, delete, ingest status/retry, private viewer, extracted text and page/section links, fast global keyword search with Ctrl+K, filters, previews and highlights, saved searches, real AI Q&A for eligible documents, citations, summary, saved answers, conversation persistence, quota/settings, audit activity, sign-out and data deletion. Search and file browsing work when AI unavailable. No unrestricted signup or shared admin account.
## P1 valuable enhancements
Compare documents with citations, extract dates/entities/action items into validated structured JSON, export cited notes as Markdown/CSV (formula-safe), timeline, document version history, cross-document Q&A, semantic search only with privacy-compatible embeddings, OCR only if safe isolated local worker is available, optional workspace roles, admin aggregate health without contents. Build only after P0. Hide unavailable capabilities; label limitations.
## Non-goals
No automated legal/medical judgments, autonomous external actions, public sharing, external drive sync, paid service or enterprise compliance. Scanned PDFs return OCR-required state if OCR not implemented. No fake vector mode. Private originals and extracted text never leave authorized storage except explicit user downloads; private docs never sent to free external AI. Public synthetic sample data may be used for real live AI.
## Acceptance
New authorized user can upload a fresh supported synthetic file, find a specific keyword within it, open source location, ask a real AI question after explicit non-sensitive eligibility, get verifiable citations, save answer and find it after refresh. Second account cannot retrieve any of first user's resources. Private upload search remains functional without provider. Delete removes searchability and access immediately and purges content through verified cleanup.
