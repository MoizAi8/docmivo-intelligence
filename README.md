# Docmivo — Find what matters.
AI document intelligence and private indexed search. This repository currently contains a pre-development kit, not a running application. Read START_HERE.md, AGENTS.md and MASTER_PROMPT.md. Planned architecture: Next.js, TypeScript, Neon PostgreSQL, indexed lexical search and genuine source-grounded AI for eligible non-sensitive data. Private document search does not require inference. Actual setup commands, screenshots, verified test results, hosted URL and limitations must be updated once implemented. No credentials or personal documents included.
